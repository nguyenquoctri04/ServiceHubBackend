# ServiceHub Backend - Implementation Checklist

- [ ] 1. Sửa file `.env`: Thêm `REDIS_URL`, `CLOUDINARY_URL`, `FRONTEND_URL` và loại bỏ các biến `PORT_` nội bộ dư thừa.
- [ ] 2. Xây dựng cấu trúc thư mục dùng chung `libs/common/src/`:
  - [ ] `exceptions/` (Global Exception Filter trả về { success, status, data, message })
  - [ ] `interceptors/` (Response Wrapper trả về { success, status, data, message })
  - [ ] `observability/` (Setup Request Context / Correlation ID và Structured Logging)
  - [ ] `decorators/` (Custom decorators)
  - [ ] `constants/` & `utils/`
- [ ] 3. Refactor cấu hình Prisma:
  - [ ] Cập nhật `generator client` trong 10 schema.prisma thành custom output (`node_modules/@prisma/client-*`).
  - [ ] Scaffold sẵn `PrismaModule` & `PrismaService` chuẩn cho các microservice.
- [ ] 4. Refactor `apps/api-gateway`:
  - [ ] Giữ lại HTTP port 3000, cấu hình Global ValidationPipe.
  - [ ] Cấu hình Global `ClientsModule` đăng ký kết nối với 10 microservices nội bộ qua Redis.
  - [ ] Gắn middleware/interceptor sinh Correlation ID (Trace ID) ở Gateway.
- [ ] 5. Refactor 10 Microservices nội bộ (Ví dụ làm trước `provider-service`): 
  - [ ] Chuyển đổi `main.ts` từ HTTP app (`app.listen`) sang `createMicroservice` (Upstash Redis). Khẳng định XÓA port 3002.
  - [ ] Thiết lập cấu trúc thư mục chuẩn: `controllers/`, `services/`, `dto/`, `modules/`.
  - [ ] **Sinh sẵn Boilerplate Test (`*.spec.ts`) cho Controller và Service với Mock (Prisma/Redis) cấu hình sẵn.**
- [ ] 6. Khởi chạy toàn bộ hệ thống (`npm run start:all`) qua Upstash Redis và verify Gateway gọi thành công vào nội bộ kèm theo Trace ID.
